# Traçabilité des exécutions

Les fichiers `etat-executions.md` et `verification-livraison.json` décrivent la livraison. Les rapports d'outils sont conservés dans les sous-dossiers correspondants et dans l'archive livrée. Une nouvelle exécution produit ses propres artefacts ; ne pas confondre résultats initiaux et résultats futurs.

Un résultat attendu, un fichier de configuration valide ou un test local ne vaut pas validation du service public. Toute campagne absente est signalée comme non exécutée.
